# RAAZ — Independently Trained Financial ML

RAAZ is NIVA's own planned model system: intent detection, entities/slots, transaction category suggestion, controlled dialogue and grounded financial explanation.

No pretrained foundation-model weights, external hosted AI endpoints or private NIVA financial-history training by default. Python, PyTorch and scikit-learn are planned **tools**, not pretrained model intelligence.

Start with project-owned/synthetic labeled Tamil, English and Tanglish examples; group-disjoint train/validation/test splits; reproducible from-scratch baselines; calibration/abstention tests; a model card and provenance review.

**No trained model exists in this repository yet.** Keep checkpoints and restricted datasets outside Git.
