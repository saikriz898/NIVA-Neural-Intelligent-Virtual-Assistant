# NIVA UI / UX Screen Map

**Mobile (planned):** Welcome → Language → eligibility check → Guest/Registered choice → profile → accounts/opening balances → Home.

Five mobile destinations: **Home, Activity, RAAZ, Plans, You**. Additional views: Accounts, Record Expense/Income, **Record Transfer**, split-bill details, who paid/has not paid, settlement history, budgets, goals, commitments, workspaces and Settings.

**Web:** public informational pages separate from authenticated Registered workspace dashboard. Guest financial records do not automatically appear in web storage.

Financial UX rules:
- Display recorded and provisional balances truthfully, never as verified live bank totals without an authorized integration.
- **Record Transfer** records an observed/manual transfer, not movement of real money.
- Splits identify who paid the original bill, each participant's share, partial repayments, outstanding amounts and payment evidence.
- Recording a repayment is not receiving bank money; reconciliation follows approved journal rules.
- Future real bank transfer integrations are separately gated.
- RAAZ prepares drafts and requests user confirmation; model unavailability never blocks basic recordkeeping.
- Initial release is adults-only pending independent minor-support approval.
