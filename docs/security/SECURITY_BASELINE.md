# Security & Data Classification

Public repository: **no** private financial records, account identifiers, receipts, conversations, credentials, encryption keys or protected backups.

Guest records: encrypted device-local authority; no automatic network upload; encrypted export/restore, with honest unrecoverable-loss warnings if backups are absent.

Registered records: authenticated services; enforce separate resource/owner scope permission on every account, workspace, report, attachment and RAAZ tool. Client route hiding is not authorization.

Finance: integer minor units, atomic balanced postings, stable idempotency identity and auditable corrections; distinguish local save, server acceptance and external bank completion.

RAAZ: project-owned controlled training data; no personal finance training by default; no pretrained foundation weights or hosted AI inference; separate ML inference process must not receive ledger write authority.

**Compliance readiness:** age safeguards, applicable legal reviews, key lifecycle, recovery drills and retention policies must be completed before production use.
