# NIVA Brand Identity — v1.0

Identity: **NIVA — Neural Intelligent Virtual Assistant**  
Tagline: **Your Money. Your Intelligence. Your Future.**  
Personality: intelligent, trustworthy, premium, minimal, privacy-conscious.

## Finalized color tokens

| Token | HEX | Usage |
|---|---|---|
| Midnight | `#081729` | Primary dark surface |
| Deep Navy | `#082D6B` | Branded text and strong UI accents |
| Electric Cyan | `#00AFFF` | Primary highlight |
| Teal | `#00D6A3` | Positive accent (not sole status indicator) |
| Platinum | `#C6CDD8` | Neutral strokes |
| Porcelain | `#F7F8FA` | Primary light surface |

Primary typeface: **Inter**; secondary optional: **Plus Jakarta Sans**, subject to license/accessibility review.

## Symbol and authenticity

The repository contains a lightweight clean SVG brand **interpretation** for documentation and UI scaffolding. It does **not** claim pixel-identical reproduction of the approved metallic N icon. The exact approved logo/app icon PNG files should be imported from the finalized NIVA Brand Kit after review. Never replace the approved brand by an unrelated generated mark without approval.

## Usage

Allow clear space around the symbol, ensure accessible contrast, use simplified artwork at small sizes, retain correct proportions and avoid gradients in monochrome assets. Splash screens are intentionally out of scope.
